# PortfolioX ❤️   
 
> A fully dynamic, motion-enhanced   portfolio built with **Next.js**, **Tailwind CSS**, **Framer Motion**, and **MongoDB** — blending clean UI, seamless animations, and real-time   interactivity.   

---
 
### ⚙️ Tech Stack   
**Next.js • TypeScript • Tailwind CSS • Framer Motion • MongoDB • shadcn/ui**  
 
---  
  
### ✨ Highlights   
- 🔥 Real-time **View & Love Counter** with database persistence    
- 🎞️ Smooth **Framer Motion** transitions for every section   
- ⚡ Optimized performance with **Next.js App Router**  
- 🧠 Modular architecture with reusable UI components  
- 🌗 Fully **responsive**, minimal, and **SEO-friendly**
